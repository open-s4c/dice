Review-fix sources based on 741e7bc. Native macOS arm64 (Apple M1).
AppleClang 21.0.0 with full/ThinLTO; GCC 12.5 with full LTO.
Release/O3 runtime DSOs, separate non-LTO callers. No sanitizer.
Two million publications/sample, five samples per case; medians below.
Each process warms up before CLOCK_MONOTONIC timing and validates capture counts.
Runtime initialization and process startup are outside the measured interval.
Constant and volatile dynamic chains both publish through Self to a capture slot.
No builds or tests ran during the measurement matrix.

open = callbacks enabled, public APIs; closed = callbacks disabled, public APIs.
sealed = callbacks disabled and all component APIs sealed.
ordinary/inline select the capture observer slot policy; Self is inline in both.
Default, chain-first, and event-first policies preserve the same handler order.
All 540 measured runs completed with exactly the expected number of events.

Interpretation
Callback-free dispatch and sealed APIs reduce costs in this small workload.
Forcing an observer inline is not universally faster: its chain-wide nested
fallback can increase dynamic-publication latency or code size. Priority and
inlining effects differ between compilers/LTO modes; these are controls, not
unconditional speedup guarantees. This microbenchmark is not an application
overhead estimate and does not predict Linux/OHOS performance.

Validation
GCC: all 69 CTests passed, including C++ delivery, missing/duplicate handlers,
exact-only priorities, and publication initialization/result parity.
AppleClang: all 69 cases passed across verification runs. The install test
passed with a fresh build directory after the existing tsan.c.tmp build race.
C++ linkage tests include unoptimized, optimized, full LTO, debug/full LTO,
and Clang ThinLTO, with callbacks and route checks both on and off.

Reproduce
Configure Release with DICE_TESTS=OFF, DICE_BENCHMARKS=ON, DICE_LTO=OFF.
Select C/C++ compilers and DICE_ROLL_BENCH_LTO=full or thin.
Build target roll-benchmarks, then run:
  cmake -DBUILD=<build> -DSAMPLES=5 -DITERATIONS=2000000 \
    -P scripts/benchmark-roll.cmake

Raw samples, sizes, symbols and disassembly:
